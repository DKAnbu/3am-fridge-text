## The entry

`main.ts` writes one line (1–140 characters) to `/output/entry.txt` — the fridge,
awake all night, finally judging its owner's 3am visits:

> I have watched you open me 4 times tonight and take nothing. Go to bed. I am not a hobby.

Six candidate lines, with character counts and angles, live in
[candidates.md](candidates.md).

## Run

```sh
node main.ts
```
